# Alarm Intelligence Dashboards

Sanitized data-preparation project for operational alarm intelligence and dashboard-ready KPI tables.

## Monitoring themes

- Power failure
- High temperature / HRT
- RU low voltage
- DU low voltage
- Low-battery conditions

The Python layer aggregates synthetic alarm events into hourly KPI tables that can feed Power BI, Excel or another visualization layer.

## Public-safe note

Synthetic data only. No live network data, client information, site coordinates or internal operational details are included.
